# 📬 Real-Time Chat Application

A real-time chat application built with **React**, **Node.js**, **Express**, **MongoDB**, and **Socket.IO**.  
It supports one-to-one messaging with unseen message counts and live updates for both sender and receiver.

---

## 🚀 Features

- **Authentication**
  - User login and registration
  - JWT-based authentication

- **Chat Functionality**
  - Real-time messaging with Socket.IO
  - Fetch previous messages from MongoDB
  - Unseen message count indicator
  - Auto-update chat window when new messages arrive
  - Message seen status

- **User Interface**
  - Sidebar with user list
  - Active chat area
  - Toast notifications for errors and info

---

## 🛠 Tech Stack

**Frontend:**
- React (with Context API)
- Axios
- React Hot Toast
- Tailwind CSS (or your CSS framework)
- Socket.IO client

**Backend:**
- Node.js
- Express.js
- MongoDB (Mongoose)
- Socket.IO server
- JWT for authentication
- bcryptjs for password hashing
